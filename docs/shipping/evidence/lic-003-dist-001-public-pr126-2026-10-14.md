## Implementation evidence

`generate-third-party-notices.mjs` now falls back to the installed pnpm virtual
store manifests when `pnpm licenses list --json` cannot read its global package
index. The fallback preserves package identity, versions, source metadata,
license grouping, installed paths, nested-component lookup, deterministic
ordering, and the existing fail-closed license-text handling. An explicit
`VERGLOS_NOTICE_FORCE_LOCAL_SCAN=1` switch makes the fallback contract directly
testable.

The regression test runs the generator twice through the local-manifest path,
asserts byte-identical output, and retains the nested `benchmark@1.0.0` review
blocker in the generated notice output.
