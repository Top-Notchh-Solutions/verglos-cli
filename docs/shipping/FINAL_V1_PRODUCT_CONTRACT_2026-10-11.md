# Verglos Final V1 Product Contract

The shipping worktree follows the shared Final V1 contract. Verglos is one
CLI for Free, Pro, Team, Studio, and Enterprise; TypeScript/JavaScript are the
initial native scanner languages; Hunt is enabled with bounded signed recipes;
Attest creates independently verifiable Release Records; and paid plans use
one-time card payments for fixed terms with manual renewal.

Team/Studio/Enterprise repository testing uses the TopNotchh GitHub
organization and forked public TypeScript/JavaScript repositories. The
integration must verify repository binding, exact commits, pull-request
delivery, replay protection, failures/retries, and removal.

Hunt must be read-only, network-denied by default, resource-limited, cleaned
up, and unable to access host sockets or secrets. Arbitrary model-generated
shell is not permitted. Attest, Hunt, and GitHub integration are not considered
shipped until implementation, tests, and private evidence exist.

This file is a worktree pointer. The authoritative contract and checkbox state
are maintained in the private shipping tracker.
