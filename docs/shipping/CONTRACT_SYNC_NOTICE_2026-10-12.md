## What is now fixed

- Verglos is a local-first, not local-only, security decision and evidence
  layer for native TypeScript/JavaScript projects.
- One CLI serves Free, Pro, Team, Studio, and Enterprise.
- Paid plans are prepaid fixed terms with manual renewal; V1 does not promise
  automatic recurring card renewal.
- Hunt is a controlled, signed, digest-pinned recipe system with four roles:
  Planner/Scout, Attack Worker, Proof Adjudicator, and Release Auditor. It is
  not arbitrary model-generated shell or an unrestricted autonomous pentester.
- Attest/Release Records are portable evidence: local verification is Free;
  signed/private records are Pro; organization approvals are Team; client and
  public verification are Studio; private governance/KMS/HSM options are
  Enterprise.
- The ten customer-facing domains are D1 input/injection, D2 auth/sessions,
  D3 authorization/tenancy, D4 secrets/crypto, D5 secure configuration, D6
  dependencies/supply chain, D7 API/service hardening, D8 source/release
  provenance, D9 network/file boundaries, and D10 containers/IaC/artifacts.
  Agent/MCP is a cross-cutting overlay, not an eleventh domain.
- Trivy is an optional replaceable open-source engine boundary for container,
  image, SBOM, and vulnerability evidence. Verglos owns normalization,
  correlation, policy, provenance, Release Records, and honest incomplete
  states; it must not claim that Trivy itself is Verglos.

## Current goal boundary

The active goal executes Points 1–5 only: synchronize the contract, implement
the real bounded Hunt/public CLI path, connect Web entitlements/Attest/Records,
and qualify the npm package on public TypeScript/JavaScript repositories and
TopNotchh-owned forks. It stops after that qualification evidence bundle.

Npm publication, held-out experiments/POC, campaign execution, and the final
release decision are next-goal work. No document synchronization changes a
backlog checkbox or proves implementation.
